# The JustPDF name and icon

The **source code** of JustPDF is free software under the GPL-3.0-or-later. You may
fork it, modify it, and redistribute it under those terms.

The **name "JustPDF"** and the **app icon / launcher graphic** are *not* covered by
that license. They identify this project and its builds specifically.

## What this means for forks

- You are welcome to fork the code.
- If you distribute a modified version, **release it under a different name and a
  different icon.** Don't call it "JustPDF" and don't use the JustPDF icon, so users
  can tell your build apart from this one.
- The GPL already prevents a closed-source or ad-supported fork (you'd have to publish
  all of your source under the GPL too). This notice is about identity, not code.

## The spirit of the project

This is a request, not a license term, because the GPL does not permit added
restrictions:

> Please don't add advertising, analytics, tracking, or any network calls to a build
> that traces back to this code, whatever you call it. The whole point of JustPDF is
> that people who just need to read a PDF shouldn't be preyed upon.

If you're building something in that spirit, thank you.
